# PantryPal - DESIGN.md

## Visual Identity & Design Language

PantryPal uses a cohesive design system that differentiates between three distinct operational areas while maintaining a shared core aesthetic.

### Core Design Principles
- **Clean & High-Contrast:** Priority on legibility and ease of use in kitchen environments.
- **Color Palette:** Professional emerald/sage greens for inventory, warm oranges for alerts/low-stock, and clean neutrals for data-heavy views.
- **Mobile-First:** All interfaces must be fully functional on small screens (kitchen usage).

---

## 1. Frontend Landing Page
**Style:** Marketing-focused, high-engagement, clean.
- **Visual Goal:** Evoke a sense of organized calm.
- **Components:**
  - **Hero:** Large, high-quality images of fresh produce/pantry storage.
  - **Typography:** Bold, serif headings (stable/trustworthy) paired with clean sans-serif body text.
  - **CTAs:** Bright, vibrant "Get Started" buttons that stand out against the background.
  - **Spacing:** Generous whitespace to highlight key features.

## 2. User Dashboard
**Style:** Utility-focused, dense but readable, tool-centric.
- **Visual Goal:** Effortless inventory management and quick scanning.
- **Components:**
  - **Bottom Navigation:** Mobile-friendly thumb navigation for the primary views.
  - **Cards:** Rounded, bordered cards for individual inventory items.
  - **Alerts:** Clear, high-contrast badges for "Low Stock" or "Expired" items.
  - **Interactions:** Subtle haptic feedback and animations for scans and updates.

## 3. Admin Dashboard
**Style:** Data-dense, analytical, functional.
- **Visual Goal:** High-level system oversight and user management.
- **Components:**
  - **Side Navigation:** Desktop-optimized sidebar for managing users, tiers, and system health.
  - **Tables:** Optimized for bulk data viewing—striped rows, sortable columns, and dense padding.
  - **Charts:** High-level metrics (Plausible/Recharts) showing user growth and API usage.
  - **Tiers:** Color-coded badges for Free, Pro, and Family accounts.
